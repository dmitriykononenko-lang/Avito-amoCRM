# План работ v1

Оценка — ~26 рабочих дней одного разработчика + ожидание канала amoCRM + пилот 2 недели.

## Этапы

- [ ] **0. Подготовка (3 дня)** — чек-лист [STAGE0.md](STAGE0.md): заявка на канал, приложение Avito, сверка swagger, прототип «чат → сделка».
- [x] **1a. Каркас** — структура, БД, очередь, подписи, шифрование, правила, тесты, CI, виджет-заготовка.
- [ ] **1b. Подключение (≈4 дня)** — OAuth amoCRM (`/oauth/amocrm/callback`), OAuth Avito, connect канала → scope_id, создание источников, `/api/amo/bootstrap`, экран настроек виджета.
- [ ] **2. Входящие чаты (5 дней)** — обработчик `avito.message`: контакт/сделка/чат, вложения (фото, голосовые), поля и UTM.
- [ ] **3. Ответы (3 дня)** — `amojo.outgoing`: текст, фото, файлы по настройке, delivery_status, анти-эхо, импорт ответов из приложения Avito.
- [ ] **4. Звонки (4 дня)** — `avito.poll_calls` раз в 2 мин, записи на VPS с подписанной ссылкой, `/calls` / unsorted SIP.
- [ ] **5. Надёжность (3 дня)** — `avito.reconcile`, проверка подписок, refresh по расписанию, Telegram-алерты, чистка inbox/файлов, статус в виджете.
- [ ] **6. Тесты и пилот (3 дня + 2 недели)** — все сценарии приёмки, инструкции, runbook, пилот.

## v2 (после пилота)
История чатов (`silent`), телефон из текста + склейка дублей, прочитано/печатает/«Написать первым», AI (квалификация, черновик ответа, резюме звонка), публикация в amoМаркете и биллинг.

## Приёмка

| # | Сценарий | Ожидаемо |
| --- | --- | --- |
| 1 | Первое обращение нового клиента | ≤ 30 с: 1 контакт, 1 сделка в нужной воронке/этапе/ответственный, поля и UTM, сообщение в чате, без лишнего неразобранного |
| 2 | Повторное сообщение в чат | Тот же чат и сделка |
| 3 | Другое объявление | Тот же контакт, новая сделка |
| 4 | После закрытия сделки | Новая сделка у того же контакта |
| 5 | Повтор вебхука ×3, два сообщения за 1 с | 1 сообщение, 1 сделка |
| 6 | Ответ из amoCRM (текст, фото) | ≤ 10 с в Avito, статус «доставлено», без эха |
| 7 | Ответ из приложения Avito | Появляется в amoCRM как исходящее, назад не уходит |
| 8 | Вложения | Фото/голос открываются; PDF — по настройке |
| 9 | Звонок: известный/новый номер | ≤ 5 мин: звонок с записью / неразобранное; без дублей |
| 10 | Истечение/отзыв токенов | Авто-refresh; при отзыве алерт ≤ 5 мин, после переавторизации события доставлены |
| 11 | amoCRM 429/5xx 10 мин; наш сервис лежит 10 мин | Всё доставлено по порядку, без дублей; потерянные ответы помечены |
| 12 | 100 сообщений туда-обратно | Счётчики сходятся, в логах нет ПДн и токенов |
